# SEO checklist – Pssst Bandido Düsseldorf

Do these in order. Code is only half of local SEO.

## 1. Replace placeholders (index.html, sitemap.xml, robots.txt)
- [WEBSITE-URL] → your final address, no trailing slash (e.g. https://waynester26.github.io/Mexican-Restaurant-Website)
- [TELEFON], [E-MAIL], [STRASSE + NR.], [PLZ], [HH:MM], [LATITUDE], [LONGITUDE], [€€]
- [INSTAGRAM-URL], [FACEBOOK-URL], [GOOGLE-BUSINESS-PROFIL-URL], [GOOGLE-BEWERTUNGS-LINK], [GOOGLE-MAPS-LINK]
- Tip: search every file for "[" to find what is left.

## 2. Google Business Profile (most important for "restaurant near me")
- Claim or create the profile at business.google.com.
- Name, address and phone must match the website EXACTLY (same spelling).
- Add category "Mexican restaurant", opening hours, menu link, reservation link, real photos.
- Ask guests for reviews and answer every review.

## 3. Google Search Console
- Add your site and verify it (uncomment the verification tag in index.html or use the HTML-file method).
- Submit [WEBSITE-URL]/sitemap.xml.
- Use "URL inspection" -> "Request indexing" for the home page.

## 4. Test
- PageSpeed Insights (mobile score), Rich Results Test (structured data), Mobile-Friendly check.
- Get an independent review of the code and SEO plan with a second AI tool and a professional SEO tool.

## 5. Content that helps ranking
- Real photos of food and rooms (you already have them). Compress the 4 big photos (~1 MB each) to under 300 KB.
- Real opening hours, real menu with prices, real reviews. Remove all placeholders before launch.
- Search terms to use naturally in text: "Mexikanisches Restaurant Düsseldorf", "Tacos Düsseldorf", "Mariachi Düsseldorf", "Mexikanisch essen Düsseldorf".

## Known limit
The site uses #/menu style views. Google treats all views as ONE page (everything after # is ignored). For stronger rankings, split it into real pages later: speisekarte.html, kontakt.html, reservierung.html, mariachi.html.
